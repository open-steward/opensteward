# Vertical icons

Square 32×32 line-art SVGs, one per vertical, all using `stroke="currentColor"` so they inherit colour from the surrounding text or the matching `--vertical-<name>` token.

Served by docs-server at `/design/icons/verticals/<name>.svg` (via the static mount of `designSystemRoot`).

| File | Vertical | Token (light) |
|------|----------|---------------|
| `accounting.svg` | Accounting | `--vertical-accounting` |
| `crm.svg` | CRM | `--vertical-crm` |
| `ecommerce.svg` | Ecommerce | `--vertical-ecommerce` |
| `logistics.svg` | Logistics | `--vertical-logistics` |
| `payments.svg` | Payments | `--vertical-payments` |
