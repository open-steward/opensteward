# Pylon adapter (slug: gorgias-aircall)

Customer-support vertical adapter for [Pylon](https://www.usepylon.com).

REST API base URL: `https://api.usepylon.com`. Auth: `Authorization: Bearer <api_key>`.
API tokens are generated by Admins in the Pylon dashboard (Settings > API Tokens).

Pagination: cursor-based via `{ data: [], pagination: { cursor, has_next_page } }`.

Webhook: HMAC-SHA256 over `concat(timestamp, '.', body)` (hex), header `Pylon-Webhook-Signature` (prefixed `hs256=`), timestamp in `Pylon-Webhook-Timestamp`.

## Supported resources
- Issues (tickets) — GET /issues (requires 30-day time window), GET /issues/{id}
- Messages — GET /issues/{id}/messages
- Contacts — GET /contacts, GET /contacts/{id}
- Users — GET /users, GET /users/{id}
- Tags — GET /tags, GET /tags/{id}
- Teams — GET /teams, GET /teams/{id}
- Macros — GET /macros, GET /macros/{id}

## Refused (schema-firewall)
- Attachment content (only attachmentCount via file_urls.length)
- Voice/call recording audio + transcripts
- AI-generated summaries
- Contact PII beyond email + name + phone
