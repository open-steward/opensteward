Secrets: source={{ .Values.secrets.source }}
{{- if eq .Values.secrets.source "plain" }}
  WARNING: secrets.source=plain renders the secrets into the release history.
  Use existingSecret / externalSecrets for production.
{{- else if eq .Values.secrets.source "generate" }}
  A hook Job generated/maintained {{ include "opensteward.secretName" . }}. It is
  NOT Helm-owned, so `helm uninstall` leaves it in place (keeping STORE_SECRET, the
  key that decrypts your data). Delete it by hand only if you mean to wipe access.
{{- if .Values.secrets.generate.bootstrapToken }}

  First-run setup is GATED by a generated BOOTSTRAP_TOKEN — the setup wizard will
  ask for it. Read it back with:
    kubectl -n {{ .Release.Namespace }} get secret {{ include "opensteward.secretName" . }} -o jsonpath='{.data.BOOTSTRAP_TOKEN}' | base64 -d ; echo
  (Disable with --set secrets.generate.bootstrapToken=false for an ungated trial.)
{{- end }}
{{- else if eq .Values.secrets.source "externalSecrets" }}
  External Secrets Operator syncs {{ include "opensteward.secretName" . }} from your
  cloud secret store. If pods CrashLoop on first boot, the ExternalSecret has not
  synced yet — check:  kubectl get externalsecret {{ include "opensteward.secretName" . }}
{{- end }}
  Pods run with NODE_ENV=production, so a weak/missing JWT_SECRET / SESSION_SECRET
  / STORE_SECRET will CrashLoop the pod (assertSecret fail-closed) — that is the
  intended behaviour, not a bug.
{{- $licenseSecret := include "opensteward.licenseSecret" . }}
{{- if $licenseSecret }}

  integration-server at /etc/opensteward/license. Renew by updating that Secret; no restart
  needed. If you created the Secret after installing, restart integration-server once:
    kubectl -n {{ .Release.Namespace }} rollout restart deploy/{{ include "opensteward.fullname" . }}-integration-server
{{- else }}

License: none configured, so OpenSteward runs in community mode (all current verticals,
  1 connection, 1 tenant). Get a free license at https://opensteward.dev/license, then set
  license.existingSecret (docs/deployment/license.md).
{{- end }}
