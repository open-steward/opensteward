# `@open-steward/placeholder` — reserved scope

This package exists solely to reserve the **hyphenated** `@open-steward` npm scope and prevent typo-squatting.

## The real OpenSteward packages live under `@opensteward`

Install instead:

```bash
npm install @opensteward/mcp-server
# or any other @opensteward/* package
```

| You probably wanted | Install |
|---------------------|---------|
| OpenSteward MCP server | `@opensteward/mcp-server` |
| OpenSteward shared library | `@opensteward/shared` |
| OpenSteward design system | `@opensteward/design-system` |
