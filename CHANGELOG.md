# Changelog

All notable user-facing changes to OpenSteward are recorded here, in
reverse-chronological order.

The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this
repository's release tags are scoped per package
(`<scope>/v<semver>`) — see `scripts/release.ts`. Operator-relevant
release notes use the unscoped section headers below; the changelog
gate in `scripts/release.ts` matches on a `## [v<semver>]` header
when tagging a new monorepo-wide release.
